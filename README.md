# 🚨 3D-CNN and Autoencoder-Based Gas Detection in Hyperspectral Images

A deep learning-based system for detecting harmful gases such as methane using hyperspectral image data, implemented with 3D Convolutional Neural Networks (3D-CNNs) and Autoencoders. The project features a Flask-based web application for real-time inference and visualization.

## 🧠 About the Project

This project aims to solve the problem of hazardous gas leakage in industrial and environmental settings by using **hyperspectral imaging** and **deep learning**. The system can detect gases like methane based on their unique spectral signatures.

---

## ✨ Features

- Gas detection using hyperspectral image data
- 3D-CNN and autoencoder-based classification
- Real-time predictions using Flask web application
- User authentication using SQLite
- Clean, responsive user interface

---

## 🛠️ Technology Stack

- Python
- Flask
- HTML, CSS, Bootstrap
- TensorFlow / Keras
- SQLite
- NumPy, Pandas

---

## 📊 Dataset

- Format: `.npy` and `.csv`
- Source: Edge Impulse methane spectral data
- Input: Hyperspectral image data across multiple wavelengths
- Preprocessed to reduce dimensionality via Autoencoder
